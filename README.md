# Radar de Inversión — proyecto completo

Subir todo este contenido a un repositorio GitHub llamado `radar-inversion`.

## Incluye
- Motor Python de análisis.
- Ranking Top 5.
- Entrada, objetivos, stop y riesgo/beneficio.
- PWA instalable en Android.
- GitHub Actions para análisis automático cada lunes.
- GitHub Pages para publicar la app.

## Desde el celular
1. Crear repositorio nuevo en GitHub.
2. Subir todos los archivos de este ZIP.
3. Ir a Settings > Pages y usar GitHub Actions como fuente.
4. Esperar la publicación.
5. Abrir la URL de Pages en Chrome Android.
6. Elegir “Instalar aplicación” o “Agregar a pantalla principal”.

## Horario
El análisis está programado para lunes 09:00 UTC, equivalente a 06:00 en Argentina (UTC-3).

## Fuente
El conector usa el histórico público documentado de Data912 como fuente de demostración. Para dinero real, sustituir el adaptador por un proveedor de Market Data adecuado/licenciado.
